## 最优阅读方法：SQ3R + 渐进摘要

经过大量研究和实践验证，最适合个人知识库的方法是将 **SQ3R** 和**渐进摘要三层法**结合使用。

### 方法一：SQ3R 阅读法（结构化阅读）

| 阶段 | 英文 | 行动 | 时间 |
|------|------|------|------|
| **预览** | Survey | 浏览目录、前言、章节标题、图表，形成整体框架 | 10-15 分钟 |
| **提问** | Question | 将章节标题转化为问题，带着问题去读 | 5 分钟 |
| **精读** | Read | 逐章阅读，寻找问题的答案，标注重点 | 主要时间 |
| **复述** | Recite | 合上书，用自己的话说出这一章的核心 | 每章 5 分钟 |
| **复习** | Review | 读完全书后回顾笔记，检验掌握程度 | 30-60 分钟 |

### 方法二：渐进摘要三层法（深度笔记）

阅读时对笔记进行三层处理，逐步提炼精华：

```
层 1 - 原文摘录：直接复制最有价值的原句
       ↓ 第二次阅读笔记时
层 2 - 加粗关键词：在摘录中标出最核心的词语或短语
       ↓ 第三次整理时
层 3 - 个人洞见：用引用块(>) 写下自己的理解、联系、启发
```

**示例：**
- 层1：「习惯的养成需要三个要素：暗示、惯例、奖励。」
- 层2：「习惯的养成需要三个要素：**暗示、惯例、奖励**。」
- 层3：> 联系到我自己：我刷手机是因为无聊（暗示）→ 刷（惯例）→ 看到有趣内容（奖励）。改变习惯的关键是替换"惯例"。

## 完整阅读流程（每本书）

### 阶段 1：读前（30 分钟）
1. 打开模板 `template.md`，按命名规范创建新文件（`books/YYYY-书名.md`）
2. 填写**基本信息**（作者、出版年、分类）
3. 浏览目录和前言（Survey），填写**概述**
4. 写下 3-5 个**阅读前问题**（Question）：你为什么读这本书？希望得到什么？

### 阶段 2：阅读中（主要时间）
- 每读完一章，在对应**章节笔记**下记录：
  - **原文高亮**：直接粘贴最重要的句子（层 1）
  - 加粗关键词（层 2）
  - `>` 写下个人洞见（层 3）
- 遇到金句随时记入**金句摘录**
- 产生行动想法随时记入**行动清单**

### 阶段 3：读后整理（1-2 小时）
1. 回顾章节笔记，提炼 3-5 条**核心收获**
2. 写下**一句话总结**（强迫自己提炼精华）
3. 给书打**评分**（1-5 星）
4. 整理**行动清单**，确定要付诸实践的内容
5. 更新 `INDEX.md` 总索引，将此书状态改为 ✅ 已读

### 阶段 4：定期复习
- **读后 1 天**：快速浏览核心收获
- **读后 1 周**：回看章节笔记，做第二层加粗
- **读后 1 个月**：写第三层洞见，更新复习记录
- 使用 `INDEX.md` 的评分列，优先复习高分书籍

## 文件结构

```
reading-library/
├── README.md        ← 你现在读的这个文件（方法论）
├── INDEX.md         ← 所有书籍一览表（总索引）
├── template.md      ← 每次复制这个来新建书籍笔记
└── books/
    ├── 2026-习惯的力量.md
    ├── 2026-原则.md
    └── ...
```

## 使用指南

### 新建一本书的笔记
```bash
# 在 books/ 目录下复制模板
cp template.md books/2026-书名.md
```

### 命名规范
- 格式：`YYYY-书名.md`
- 示例：`2026-原则-瑞-达利欧.md`
- 同年多本书：`2026-01-习惯的力量.md`（加月份）

### 分类参考
- 认知/心理、商业/管理、传记/历史、科学/技术、文学/人文、个人成长、投资/金融

### 搜索技巧
在 `books/` 目录下全文搜索关键词，快速找到相关笔记：
- VS Code：`Ctrl+Shift+F` 在文件夹中搜索
- 命令行：`grep -r "关键词" books/`

## 为什么这套方法有效？

1. **SQ3R** 利用主动提问激活大脑，避免"读完即忘"的被动阅读
2. **渐进摘要**让你在不同时间点反复接触同一内容，符合记忆的间隔效应
3. **一句话总结**强迫提炼，暴露真正理解了什么
4. **行动清单**将知识转化为行动，避免只读不用
5. **索引系统**让知识可检索、可关联，形成真正的个人知识库
